# Code of conduct

This repository hosts a public comment period on a technical specification, in a
forum that includes direct competitors. The standard is simple.

## Expected

- **Debate the specification, not the people commenting on it.** "This field
  cannot express X" is a contribution. "Only someone who has never run an ad
  server would propose this" is not.
- **Assume the other reading is held in good faith.** Buyers, sellers, SSPs and
  ad servers read the same draft differently because their constraints differ,
  not because anyone is being obtuse.
- **Be concrete.** A scenario beats an assertion.
- **Accept a documented rejection.** Every comment gets a written reason. If you
  disagree with the reasoning, reply on the issue with new information —
  reposting the same point in a new issue is not an appeal.

## Not accepted

- Personal attacks, harassment, or demeaning comments about a person, an
  organisation, or their competence.
- Sustained disruption of discussion, or reopening settled dispositions without
  new information.
- Publishing others' confidential information, or your own employer's, in a
  public repository.
- Using the comment period to advance a commercial position dishonestly —
  misrepresenting what a proposal would do, or astroturfing a position through
  multiple accounts.

## Anti-trust

Do not discuss pricing, rate-setting, market allocation, or refusals to deal.
See [GOVERNANCE.md](GOVERNANCE.md#anti-trust-and-ipr).
